# Implementation Plan: Fix Critical User Issues

## Overview
Fix 4 critical issues reported by the user related to data persistence, hours calculation, UX improvements.

---

## Problem 1: Data Disappearing in "Loads" (Step 3)

### Root Cause Analysis
**The workloads are NOT being saved to the server!**

In `state.js`, `saveSchoolDataToServer()` only saves:
- subjects, classes, teachers, classrooms

**Missing**: `workloads`, `planItems`, `availability`, `teacherAssignments`

When user logs in again or data is loaded from server, workloads are lost.

### Solution
1. **Modify `state.js`** - Include workloads, planItems, availability in server save:
   - Add to `dataToSave` object in `saveSchoolDataToServer()`
   - Load these in `loadSchoolDataFromServer()`

2. **Files to modify:**
   - `/static/js/state.js` - lines ~30-50 (saveSchoolDataToServer function)
   - `/static/js/state.js` - lines ~55-85 (loadSchoolDataFromServer function)

## Problem 2: Hours Per Quarter/Year

### Requirements
- Add `quartersCount` setting (4 or 5) on Step 1 "Profile"
- Add fields: hours/week (exists), hours/quarter (new), hours/year (new)
- Formula:
  - weeks_per_year ≈ 35
  - weeks_per_quarter = 35 / quartersCount
  - hours_per_quarter = hours_per_week × weeks_per_quarter
  - hours_per_year = hours_per_week × 35

### Solution
1. **Modify `state.js`** - Add `quartersCount: 4` to schoolData defaults

2. **Modify `index.html`** - Add quarters count dropdown to Step 1:
   ```html
   <div class="form-group">
       <label>Количество четвертей</label>
       <select id="quartersCount">
           <option value="4">4 четверти</option>
           <option value="5">5 четвертей</option>
       </select>
   </div>
   ```

3. **Modify `wizard.js`** - Update `completeStep(1)` to save quartersCount

4. **Modify `index.html`** - Update plans table headers:
   - Add columns "Часов/четв", "Часов/год"

5. **Modify `app.js`** - Update `renderPlanItems()` to show calculated hours:
   - Add helper function `calculateQuarterHours(hoursPerWeek)`
   - Add helper function `calculateYearHours(hoursPerWeek)`

6. **Files to modify:**
   - `/static/js/state.js` - add quartersCount to schoolData
   - `/static/index.html` - Step 1 form (line ~180), plans table (line ~430)
   - `/static/js/wizard.js` - completeStep(1), restoreStep1Fields()
   - `/static/js/app.js` - renderPlanItems(), addPlanItem()
